## 流量超了会怎样，还有哪些限制

各档月流量从 500G 到 6000G。超量之后是限速、停机还是可以加购流量包，公开价目和条款摘要里没写清楚，下单前用工单问一次是最稳的。同类商家在这件事上差别很大：有的超量后限速到 1Mbps，这个速度只能挂着不掉线，跑业务没戏；有的直接停机，等你下个月流量重置。

几个买之前该知道的限制：

- **机房只有三个。** 圣何塞、法兰克福、伦敦。美西就圣何塞一个点，想要洛杉矶多线路分开卖的结构，这家不是。
- **IP 归属。** 德国节点标注了原生 IP，圣何塞这档没有看到原生 IP 的明确标注。买美西是为了解锁流媒体、做注册类业务的，下单前找客服确认 IP 段，别自己猜。
- **支付和界面。** 全中文，支持支付宝，国内用户没有付款门槛。
- **硬盘。** 全系 SSD，容量从 10G 到 40G。10G 装完系统剩不下多少，跑 Docker 镜像的从 15G 起。
